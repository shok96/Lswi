# LSWI

Трей-приложение, которое исправляет текст, набранный не в той раскладке. Выделите `ghbdtn` — двойное нажатие горячей клавиши заменит его на `привет`.

Работает на **Windows**, **macOS** и **Linux**. Это не клон Caramba Switcher: только замена выделенного текста, иконка в трее и автозапуск.

## Как пользоваться

1. Выделите текст, набранный в неправильной раскладке.
2. Дважды быстро нажмите назначенную клавишу (по умолчанию **Shift**).
3. Выделение заменится по таблице EN ↔ RU (`qwerty` ↔ `йцукен`).

На Windows настройки открываются из трея. На macOS и Linux все опции в меню иконки: включение, автозапуск, смена системной раскладки после замены, назначение клавиши, интервал двойного нажатия.

Системную раскладку клавиатуры после замены текста программа **не переключает**, если это не включено отдельно.

## Сборка

Нужны [Rust](https://rustup.rs/) и Cargo.

```bash
cargo build --release
```

Готовый файл:

- Windows: `target/release/lswi.exe`
- macOS / Linux: `target/release/lswi`

### Windows

Дополнительных системных библиотек не требуется.

### macOS

В **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ** нужно разрешить LSWI (или Terminal / iTerm, если запускаете оттуда). Без этого глобальная клавиша не работает.

Автозапуск — LaunchAgent `~/Library/LaunchAgents/com.lswi.app.plist`.

### Linux

Глобальный перехват клавиатуры надёжнее на **X11**. На чистом Wayland хук часто недоступен.

Для сборки обычно нужны GTK 3, pkg-config и заголовки X11/Wayland, например:

```bash
# Debian / Ubuntu
sudo apt install build-essential pkg-config libgtk-3-dev libx11-dev libxtst-dev
```

Автозапуск — `~/.config/autostart/lswi.desktop`.

## Настройки

Файл `settings.json`:

| Система | Путь |
| --- | --- |
| Windows | `%APPDATA%\Lswi\settings.json` |
| macOS | `~/Library/Application Support/Lswi/settings.json` |
| Linux | `~/.config/Lswi/settings.json` |

| Поле | Смысл |
| --- | --- |
| `enabled` | Слушать горячую клавишу |
| `hotkey_vk` | Клавиша для двойного нажатия (коды как у Windows VK) |
| `double_tap_ms` | Максимальный интервал между нажатиями |
| `start_with_windows` | Автозапуск при входе в систему |
| `switch_layout_after` | После замены текста переключить системную раскладку |
